# Python Job Listings Scraper

Web scraper yang mengumpulkan daftar lowongan kerja dari situs Fake Python Jobs.

## Project URL
https://realpython.github.io/fake-jobs/
https://roadmap.sh/projects/job-listings-scraper

## Fitur
- Mengambil Job Title, Company Name, Location, dan Job Detail URL
- Menyimpan hasil ke file CSV
- Menangani error sederhana

## Cara Menjalankan
pip install requests beautifulsoup4
python job_scraper.py

## Teknologi
- Python
- Requests
- Beautiful Soup (bs4)
- CSV module
